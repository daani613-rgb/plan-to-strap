# תוכנית לסטרפ

פיילוט: תוכנית אדריכלית (PDF/PNG/JPG) לקובצי DXF בשכבות של AutoSTRAP, קומה אחרי קומה.
העיבוד נעשה כולו בדפדפן של המשתמש. התוכנית לא נשלחת לשום שרת.

הכלי מכין גיאומטריה בלבד. ההחלטות ההנדסיות והאחריות הן של המהנדס.

תוכנית הדוגמה: Swiss Dwellings v3.0.0, Archilyse AG, CC BY 4.0, DOI 10.5281/zenodo.7070952.
ספריות: OpenCV.js 4.10 (Apache 2.0), PDF.js 3.11.174 (Apache 2.0), נטענות מ-jsDelivr.
